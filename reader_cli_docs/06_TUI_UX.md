# ReaderX 当前 CLI / TUI 交互

本文档只描述当前已实现的交互，不包含首页、书架面板等尚未落地的界面设想。

## 1. 两种阅读模式

| 模式 | 进入条件 | 行为 |
|---|---|---|
| TUI | stdin/stdout 都是终端，且未传 `--plain` | Bubble Tea 全屏阅读 |
| Plain | 传 `--plain`，或运行环境不是交互终端 | 输出当前章节标题和正文 |

入口：

```bash
readerx read <book-id>
readerx read <book-id> --chapter <chapter-no>
readerx continue
readerx read <book-id> --plain
```

直接执行 `readerx` 只显示 Cobra 帮助，不会进入 TUI 首页。

## 2. 阅读界面

TUI 固定由三部分组成：

```text
《书名》 章节标题
正文区域
Ch 3/20 | 12% | Page 2/8 | ...
```

- 标题过长时按终端显示宽度截断。
- 正文左右各保留 2 列边距。
- 状态栏根据宽度使用完整、紧凑或极简格式。
- `reader.width` 限制正文最大宽度，默认 100，最小 20。

## 3. 快捷键

| 快捷键 | 功能 |
|---|---|
| `j` / `↓` | 下一行 |
| `k` / `↑` | 上一行 |
| `Space` / `PgDn` / `→` | 下一页 |
| `u` / `PgUp` / `←` | 上一页 |
| `Home` | 当前章开头 |
| `End` | 当前章最后一整页 |
| `n` / `p` | 下一章 / 上一章 |
| `g` | 输入章节号并跳转 |
| `/` | 搜索当前书，结果中用 `j/k` 选择、Enter 跳转 |
| `b` | 保存当前位置书签 |
| `m` | 输入并保存当前位置笔记 |
| `s` | 手动保存进度 |
| `?` | 打开或关闭帮助 |
| `Esc` | 关闭帮助或取消输入状态 |
| `q` / `Ctrl+C` | 保存并退出 |

## 4. 排版与分页

`internal/reader.Paginator` 完成以下工作：

- 使用 `go-runewidth` 计算终端显示宽度。
- 按 rune 逐个换行，保留原始段落空行。
- 根据正文高度计算当前页和总页数。
- 最后一页从“最后一整屏”开始，避免只剩少量文字贴在顶部。
- 记录每个排版行对应的字符起始偏移。

终端 resize 后会按新宽高重新分页，并把当前 `line_offset` 限制到合法范围。当前不会根据 `char_offset` 精确重建 resize 前的视觉位置，因此宽度变化较大时仍可能发生轻微跳动。

## 5. 进度保存

以下操作会保存：

- `s`
- 切换或跳转章节
- 添加书签
- 添加笔记
- 退出 TUI

保存字段：`book_id`、`chapter_no`、`line_offset`、`char_offset`、`percentage`，同时更新 `books.last_read_at`。

全书百分比按下式近似计算：

```text
(已完成章节数 + 当前章已翻页比例) / 总章节数
```

## 6. 搜索、书签和笔记

### 书内搜索

- `/` 进入关键词输入。
- 搜索范围固定为当前 Book ID，最多返回 20 条。
- 结果显示书名、章节号、章节标题和单行摘要。
- Enter 跳到选中结果所在章节的开头，不定位到关键词字符位置。

### 书签

- 先保存当前进度。
- 保存当前章节、行/字符偏移和 36 个 rune 左右的摘录。
- 状态栏显示生成的 Bookmark ID。

### 笔记

- `m` 后在状态栏输入单行文本。
- Enter 保存；空内容会报错。
- 当前没有 TUI 内笔记列表或编辑界面。

## 7. 主题与可访问性

支持 `default`、`dark`、`light` 三种主题。核心导航不依赖颜色，窄终端仍保留章节、进度、页码、帮助和退出提示。

当前限制：

- 没有鼠标操作、目录面板、书架首页或设置面板。
- 输入框是轻量状态机，不支持多行编辑、光标移动和复杂输入法编辑能力。
- 搜索命中不会在正文中高亮。
- 超大章节会整章加载和分页。
