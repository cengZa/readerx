# 06. CLI / TUI 交互设计

## 1. 交互原则

Reader CLI 同时支持两种模式：

| 模式 | 说明 |
|---|---|
| CLI 命令模式 | 适合自动化、快速操作 |
| TUI 交互模式 | 适合沉浸式阅读 |

## 2. CLI 命令模式

### 基础命令

```bash
reader import ./book.txt
reader list
reader read 1
reader read 1 --chapter 12
reader continue
reader search "keyword"
reader bookmark list
reader config get
```

### 设计原则

- 命令清晰
- 输出可读
- 错误信息明确
- 尽量支持脚本化
- 后续可增加 `--json`

## 6. 阅读快捷键

| 快捷键 | 功能 |
|---|---|
| `j` / `↓` | 下一行 |
| `k` / `↑` | 上一行 |
| `Space` | 下一页 |
| `u` | 上一页 |
| `n` | 下一章 |
| `p` | 上一章 |
| `g` | 跳转章节 |
| `/` | 搜索 |
| `b` | 添加书签 |
| `m` | 添加笔记 |
| `s` | 保存进度 |
| `q` | 退出并保存 |

## 7. 状态栏

状态栏建议显示：

```text
书名 | 章节 | 进度 | 当前页 | 快捷键提示
```

示例：

```text
剑来 | 第12章 | 32% | Page 4/21 | b bookmark / q quit
```

## 8. 文本排版

### 需要处理的问题

- 终端宽度
- 中文字符宽度
- 英文换行
- 段落缩进
- 空行压缩
- 标点处理

### 推荐规则

- 默认阅读宽度 80
- 左右边距 2
- 中文段落首行缩进 2 个中文空格
- 连续空行压缩为 1 行
- 保留章节标题

## 9. 终端尺寸变化

当终端 resize：

1. 获取新的 width / height
2. 用 char_offset 重新计算 line_offset
3. 重新分页
4. 保持用户当前位置尽量不跳动

## 10. 主题

第一阶段支持：

```text
default
dark
light
```

后续可支持：

```text
sepia
focus
minimal
```

## 11. 错误提示

错误信息应该明确：

错误：

```text
error
```

正确：

```text
未找到 Book ID=12 的书籍，请先使用 reader list 查看可用书籍。
```

## 12. 自动保存

推荐策略：

- 切章节时保存
- 退出时保存
- 每隔 30 秒保存一次
- 添加书签时保存

## 13. 可访问性

- 不强依赖颜色
- 所有操作有快捷键
- 重要信息用文字表达
- 支持窄终端降级显示
